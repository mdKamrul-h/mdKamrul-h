How I Build Production AI

  • Model proposes, human approves, code commits — LLMs never write live records; approval queues are the spine of every product.
  • Right-size the model — tiered routing sends volume work to small models (Haiku/Flash) and reserves frontier reasoning for where it pays.
  • Deterministic core, generative shell — pricing math, AQL verdicts, and state machines live in code; the model narrates and drafts.
  • Budgets on everything — agent loops are step-capped, token-capped, time-capped, and cost-capped; tenant isolation is enforced in Postgres, not in the prompt.
